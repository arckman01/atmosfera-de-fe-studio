Atmósfera de Fe Studio

Política de privacidad

Atmósfera de Fe Studio utiliza los permisos de las cuentas que conectas para analizar publicaciones y preparar videos.

Datos que utiliza

La aplicación consulta títulos o descripciones y métricas disponibles, como vistas, Me gusta, comentarios y compartidos. Compara las publicaciones recientes para identificar temas que han recibido más interacciones.

Datos que se comparten

Cuando eliges crear un video, la aplicación envía a OpenAI el tema editorial, los títulos y las métricas de las publicaciones destacadas. También envía instrucciones para generar imágenes y texto para sintetizar la voz. Si eliges enviar el video, lo transfiere a las plataformas seleccionadas.

Almacenamiento y control

Las credenciales se guardan en el archivo de configuración de tu equipo. Los análisis, guiones, imágenes, audios, videos y registros de envío se guardan en la carpeta de resultados. Puedes eliminar esos archivos de tu equipo cuando quieras.

Para desconectar una cuenta, revoca el acceso desde la plataforma correspondiente y borra su token de la configuración local. Para retirar un video ya enviado, gestiona ese contenido desde la plataforma que lo recibió.
