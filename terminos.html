Atmósfera de Fe Studio

Términos de servicio

Atmósfera de Fe Studio es una herramienta de escritorio para analizar publicaciones de cuentas autorizadas y crear videos cristianos a partir de sus temas.

Uso de las cuentas

Utiliza la aplicación únicamente con cuentas propias o que tengas permiso para administrar. Tú eliges las cuentas de destino y eres responsable de proteger sus credenciales.

Creación y envío de videos

Revisa el contenido generado y comprueba que tienes derecho a usar los materiales que publiques. En TikTok, la aplicación envía el video a tu bandeja para que puedas editarlo, elegir su audiencia y decidir si lo publicas.

Si seleccionas el envío a YouTube o Facebook, la aplicación solicita la carga con la configuración elegida. La generación de contenido puede generar cargos en tu cuenta de API de OpenAI.
